# Location Véhicules PFE

Application web de location de véhicules.

## Technologies utilisées

- PHP
- MySQL
- HTML / CSS
- JavaScript
- TCPDF
- PHPMailer

## Description

Ce projet a été réalisé dans le cadre du projet de fin d'études (PFE).
Il permet de gérer une plateforme de location de véhicules.

## Installation

1. Cloner le projet.
2. Installer les dépendances nécessaires.
3. Configurer la base de données.
4. Configurer les paramètres de connexion.
5. Lancer l'application sur un serveur local.
